# Development Docs

`AGENTS.md` is the quickstart. These docs are the second stop when the task needs more context.

- `REPO_MAP.md`: fastest file-routing guide by feature area
- `VALIDATION.md`: focused build/test/probe commands, hardware gates, TCC notes, and runtime log tips
- `ADDING_DEVICE_SUPPORT.md`: transport-by-transport bring-up checklist, safe probing, and scoped evidence claims
- `device-validation.json`: incremental hardware-validation claims checked against the offline Swift profile catalog
- `REVIEW.md`: pinned reviewer packets, read-only handoffs, and exact-input validation receipts
- `../../CODING_STANDARDS.md`: review-time design/evidence/release conventions (mechanical policy stays in checks)
- `SOURCEKIT_LSP.md`: SourceKit-LSP and Codex MCP setup for semantic Swift navigation, references, hover, and diagnostics

Use `docs/protocol/PROTOCOL.md` for transport/protocol work.
